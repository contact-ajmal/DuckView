Why DuckView

Most “SQL UIs” stop at the query box.

DuckView is a complete data workspace built on a native DuckDB engine per workspace — no Python sidecars, no JDBC, no data leaving your machine unless you ask it to.

Query anything, instantly

Parquet, CSV, JSON, Excel, DuckDB files, S3 / R2 / GCS / Azure objects — and Iceberg catalogs on AWS Glue, S3 Tables, any Iceberg REST catalog and Databricks. Drop a file, add a folder from anywhere on the machine, or pick a bucket, and it is queryable in seconds.

Every source, one page New in 1.2

PostgreSQL, MySQL, Snowflake, BigQuery, Redshift, ClickHouse, Fabric, Salesforce, HubSpot, Stripe, GA4, Airtable, Notion, Google Drive and Sheets — health-checked, browsable in place, credentials write-only. Syncs keep the data fresh on a schedule, with transformations validated before they save.

Data apps on your data New in 1.2

Streamlit apps written with the duckview SDK — or generated from a dashboard — run by DuckView next to the engine, served to the workspace with a read-only token. Agents create, preview and publish them over MCP. How it works.

Agent-native from day one

A hardened MCP server plus a REST / OpenAPI façade expose the same tools to Claude Desktop, Cursor, Claude Code, Strands, LangGraph, CrewAI and Bedrock AgentCore. Every mutation is held for human approval.

DuckCopilot

An in-app assistant hydrated with your live schema, files, buckets and the SQL you are writing. Fourteen providers — Claude, ChatGPT, Gemini, DeepSeek, OpenRouter, Kimi, Groq, Mistral, Grok, Ollama, Bedrock, your own agent — configured from the console with write-only keys.

From profile to dashboard

Auto-profiling on load (KPIs, null ratios, distributions), a tabbed IDE-style workbench with charts, plans and profiles, and a drag-and-drop BI dashboard builder with auto-refresh.

Cross-filter millions of rows

Explore any file, table or query as linked charts, or write a Mosaic dashboard spec with a live preview — generated from your data in one click. Powered by Mosaic's data cubes, computed in the workspace engine, never in the browser.

Built for teams

Share a workspace with people or teams as viewer, editor or owner. Dashboards and saved queries are shared; tabs stay personal. Teams mirror your IdP groups over OIDC, so okta:finance is a share target on day one.

Enterprise hardening

Filesystem jail, DuckDB lock_configuration, per-workspace memory and thread limits, AES-256-GCM credential vault, scoped API tokens, audit log, Prometheus + OpenTelemetry, OIDC with group → role mapping.

Product tour

Everything from the first file to the executive dashboard.

Overview — every source in one bar, profiled on arrival

The data source bar maps the workspace: Local — the data directory, folders mounted from this computer, the workspace's tables — and Remote, every connection you configured, browsable in place. Pick anything and DuckView profiles it immediately, computed by DuckDB, never sampled by hand.

  • Row and column counts, type mix, null ratios, duplicate rows, distributions
  • Uploads land in the data directory or any folder you choose
  • Warehouse tables, SaaS objects and Sheets tabs import through a sync in one click

Workbench — an IDE for SQL

Tabs with per-tab Stop, cursor and draft persistence, a schema explorer that opens when you click a file, chart / plan / profile views, .sql import and export, a saved-query library with folders and tags, and streaming results over WebSocket.

  • Every pane is a resizable splitter; every component can be hidden and restored
  • Engine picker: DuckDB or any Databricks SQL warehouse per tab
  • Last result of every tab comes back after a reload

Connections & syncs — one page for every source

Object storage, lakehouse catalogs, PostgreSQL / MySQL / SQLite, Snowflake, BigQuery, Redshift, ClickHouse, Fabric, Salesforce, HubSpot, Stripe, GA4, Airtable, Notion, HTTP endpoints, Google Drive and Sheets with your Google account. Each card opens the form for that source; each connection shows its health and is browsed in place.

  • Scheduled syncs (interval or cron) into workspace tables, replace or append, with a run history
  • Transformations over {{raw}}, validated before saving — drafted by Copilot or set by agents
  • Credentials encrypted and write-only; rows staged through the connector, never through the engine

Mosaic dashboards — cross-filter millions of rows

A declarative spec becomes a dashboard where every chart filters every other: menus, sliders, KPI cards, timelines, histograms, heat maps and tables share one crossfilter, computed as data cubes in the workspace engine.

  • Editor with live preview; generated from any table or file in one click
  • Drafted by Copilot or created by agents, validated against your data before saving
  • Datasets materialised once in memory — 3.7 million taxi trips answer every brush in milliseconds

Data apps — Streamlit on the workspace's data

Write an app with the duckview SDK, generate one from a dashboard or saved queries, or let Copilot draft it. DuckView creates the Python environment, runs the app, checks its health and serves it to the workspace's members with a read-only, workspace-scoped token.

  • Editor with Python highlighting next to the live preview; ⌘S saves and restarts
  • Agents: create_app → preview_app (a screenshot) → update_app → publish_app
  • pip install duckview to use the SDK anywhere else

Dashboards — from query to executive view in minutes

KPI, chart, table and Markdown widgets on a drag-and-drop grid with auto-refresh. Widgets run the same guarded queries as the workbench — and agents can build dashboards for you through create_dashboard_widget.

  • Widgets bound to saved queries or ad-hoc SQL
  • Auto-refresh that costs nothing when the data has not changed
  • Shared with every member of the workspace

Agent & MCP hub

Register an agent — Strands, LangGraph, LangChain, CrewAI, AgentCore Runtime / Gateway, Bedrock Agents or anything custom — and DuckView mints a workspace-scoped token, shows a copy-paste snippet with the token filled in, and attributes every call in the live inspector.

  • 25 tools, 4 resources and 5 guided prompts — one registry behind MCP, REST and OpenAPI 3.0, so they can never drift
  • Results capped, strings truncated, paths jailed
  • Every mutating statement returns an approval challenge until a human re-issues it

Built for AI agents

Safety is not optional.

Agents are first-class users with the same sandbox, the same audit trail and one extra rule: nothing mutates without a human.

  • MCP over stdio, SSE and Streamable HTTP

Result cache

Fast the second time — and never stale.

A two-tier result cache: shared on the server, per user in the browser. Keys embed each file's size and modification time plus a workspace data epoch that every mutation moves — so a hit is exact, not a guess.

9 938 ms → 3 ms

Overview profile of a 387 MB CSV: cold, then from the shared server cache. A confirmed-current 304 takes 2 ms and no DuckDB work.

Correct by construction

Every mutation, upload, folder change and engine restart funnels through one choke point that bumps the epoch. Non-deterministic SQL and remote sources are handled explicitly.

Instant on return

IndexedDB restores profiles, schemas, plans, widgets and the last result of every tab the moment the page opens, then quietly revalidates. Wiped on sign-out.

Themes

Six themes, one system.

Colour and typeface applied through runtime CSS variables so every component — charts, code editor, gauges — follows. First visit follows your OS scheme.
